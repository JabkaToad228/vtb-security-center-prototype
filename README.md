# Центр безопасности — кликабельный прототип

Прототип антифрод-раздела мобильного банка для кейс-чемпионата. Сделан по макету из Figma (Frame 17–22) и дополнен мини-играми, AI-помощником и историей защиты. Всё работает в браузере без бэкенда: ответы AI-помощника и сценарии подготовлены заранее.

> Прототип для кейс-чемпионата. Не является официальным приложением банка. Все данные вымышлены.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. На компьютере прототип показывается в рамке iPhone с панелью быстрых переходов слева; на телефоне — во весь экран.

## Сборка и публикация

- `npm run build` — сборка в `dist/` (открывается с любого пути, роутинг через `#/`).
- `npm run build:single` — один файл `dist-single/index.html` со всеми картинками и шрифтами. Запасной вариант на случай, если на площадке нет интернета: открывается двойным кликом.
- GitHub Pages: залейте репозиторий на GitHub, в **Settings → Pages** выберите источник **GitHub Actions**. Workflow `.github/workflows/deploy.yml` соберёт и опубликует прототип при каждом пуше в `main`.

Прототип «живой»: проценты защиты и цифрового здоровья пересчитываются от действий, прогресс сохраняется в браузере. Сбросить всё к состоянию макета — кнопка «Сбросить демо» в панели слева или в шестерёнке на любом экране.

## Сценарий показа (3 минуты)

1. **Главная** — 75% защиты. Объясняем идею: один центр для всех антифрод-функций.
2. **Риск-профиль** → «Разобрать звонок»: разбор подозрительного звонка, что заметил AI. Назад → «Я знаю звонившего» / чек-лист «Подтверждение входа» — процент на главной растёт.
3. **Круг доверия** → карточка Папы с красным статусом → «Безопасность пользователя» → баннер новой ситуации → **Разбор ситуации** (оплата по ссылке, деньги не списаны).
4. **Помощь близким** — тумблеры: что именно я получаю о близком.
5. **AI-помощник** — вставить `http://vtb-bonus.ru/pay` (фишинг) и `https://online.vtb.ru` (безопасно), спросить «мне звонят из банка».
6. **Игры** — «На связи»: ответить на звонок «службы безопасности» и увидеть подсказки AI во время разговора. Цифровое здоровье растёт.

## Где править тексты

Весь контент лежит в `src/data/`: кейсы (`cases.ts`), близкие (`people.ts`), чек-лист и веса процентов (`risk.ts`), ответы помощника (`assistant.ts`), игры (`games/*.ts`). Экраны только отображают эти данные.

Ассеты из Figma — `src/assets/figma/`. Чтобы заменить иконку, положите файл с тем же именем.

## Стек

Vite, React 18, TypeScript, Tailwind CSS 4, Motion, React Router (HashRouter), шрифт Montserrat (`@fontsource`, работает офлайн).
